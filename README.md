# GTDuino-OS-2.0-Arduino-
Esse é um sistema operacional simples desenvolvido para o Arduino UNO, esse sistema operacional foi inspirado no sistema operacional Symbian OS da Nokia. 

# Funções:
Bloco de notas
Flappy Bird
Configurações
Dino Game
Snake
Musicas
Music Maker
Geometry Pocket 
Among Us
Tetris
Pré-Escrita

# Recursos Necessários:
Um Arduino UNO, Tela OLED 0.96 (optimizado apenas para essa tela), Teclado de membrana numérico matriz 4x4 16 teclas, Alto falante ou Buzzer de bip, Bateria 9V (opcional), Arduino IDE.

# Bibliotecas Necessárias:
Adafruit GFX Library,
Keypad,
Adafruit SSD1306,
